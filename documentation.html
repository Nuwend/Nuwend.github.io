HTML Basics

HTML provides the structure of a web page using elements and tags.

Most HTML documents begin with a document type declaration followed by the root html element.

<h1>Hello World</h1>
  • HTML describes the structure of a webpage.
  • Elements can contain text and other elements.

CSS Fundamentals

CSS controls the visual appearance of HTML elements.

Styles can change colors, fonts, spacing, borders, and the layout of a page.

body { font-family: Arial, sans-serif; }
  • CSS stands for Cascading Style Sheets.
  • Selectors determine which elements receive styles.

JavaScript

JavaScript adds behavior and interactivity to web pages.

Variables can store information that your program can use later.

let message = "Hello World"; console.log(message);
  • JavaScript can respond to user actions.
  • Functions allow code to be reused.

Responsive Design

Responsive design allows a website to adapt to different screen sizes.

Media queries can apply different CSS rules depending on the width of the device.

@media (max-width: 768px) { }
  • Responsive pages work on phones, tablets, and computers.
  • Flexible layouts help content fit different screens.

Useful Practices

Writing organized code makes websites easier to maintain and understand.

Use meaningful names for classes, IDs, variables, and functions.

const userName = "Alex";
  • Keep your HTML properly organized.
  • Use comments when they improve understanding.
  • Test your website at different screen sizes.
